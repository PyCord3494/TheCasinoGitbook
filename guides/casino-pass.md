# 🎟️ Casino Pass

Casino Pass is a 30-level monthly progression track. Earn Casino Pass XP through play and claim randomized economy rewards and collectible cosmetics as levels are reached.

## Reward paths

Everyone receives the free path. Donators unlock the path matching their membership tier.

| Path | Reward scale |
| --- | ---: |
| Bronze | 0.75× |
| Silver | 1× |
| Gold | 1.25× |
| Diamond | 1.6× |
| Platinum | 2× |

Every monthly pass is generated from a new deterministic shuffle. Its free and paid economy rewards change together, while paid paths always retain stronger value than the free path. Cosmetic milestones form a deliberate quality ladder: free, Bronze, Silver, Gold, Diamond, then Platinum.

## Monthly cosmetics

Each pass can contain six collectible cosmetic milestones. The selection only uses event collections whose acquisition window overlaps the current month. For example, a December pass can feature winter and New Year pieces, but cannot pull a Valentine reward out of season.

Pass cosmetics can include titles, badges, frames, auras, taglines, and profile trackers. A collected piece is account-bound and remains usable forever—even after its event and monthly pass end. Higher membership paths inherit rewards from lower unlocked paths as they progress.

Use `/donate` or the support server for current membership information.

## Commands

* `/casino_pass help` — overview of the system.
* `/casino_pass progress` — see your monthly XP, level, and claimable rewards.
* `/casino_pass rewards [tier]` — preview all 30 rewards for any tier.

Players can preview every path, but only the free path and an eligible unlocked donor path can be claimed. Non-donors may occasionally receive temporary Silver access while playing.

## Monthly reset

Progress and unclaimed reward eligibility reset when a new monthly pass begins. Claimed cosmetics never expire and are never removed from the Cosmetic Locker.
