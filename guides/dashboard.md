# 🌐 Website Dashboard

The dashboard is the website version of The Casino. Sign in with Discord to access the same account used by the bot.

## What you can do

* View your profile, wallet, bank, statistics, achievements, and leaderboard position.
* Deposit or withdraw credits on the Bank page.
* Play interactive casino games with live balances.
* Browse, buy, sell, and use supported items.
* Create auctions, bid on listings, buy won items, and review auction history.
* Open Standard through Platinum crates in The Vault.
* Review recent game history and Casino Pass progress.
* Configure Responsible Play limits.

## Account synchronization

The dashboard does not create a separate economy. Actions are sent to The Casino server and saved in the bot's database. If you have not created an account yet, run `/start` in Discord first.

## If live data does not load

1. Refresh the page once.
2. Sign out and sign back in with Discord if the session is old.
3. Confirm `/balance` works for the same Discord account.
4. Wait briefly if the server is restarting or temporarily unavailable.
5. Contact the support server if only one action repeatedly fails.

Do not repeatedly submit a purchase, wager, bid, or transfer while its result is unknown. Check your balance or history first.

## Responsible Play

The Responsible Play page lets you configure play limits. Limits are enforced by the server, so they apply to supported dashboard wagers rather than being cosmetic browser settings.
