# 💎 Diamonds

Diamonds are The Casino's premium reward currency. They provide optional upgrades, cosmetics, and convenience without preventing players from using ordinary games, earning commands, banking, or the credit shop.

## Commands

| Command | Purpose |
| --- | --- |
| `/diamonds info` | Show every current Diamond source and use. |
| `/diamonds balance` | Check your Diamond balance. |
| `/diamonds market` | Browse optional feature and item bundles. |
| `/diamonds redeem <reward> [amount]` | Purchase one or more Diamond Market bundles. |
| `/diamonds exchange <amount>` | Convert Diamonds into wallet credits. |
| `/diamonds passxp <amount>` | Purchase XP for the current monthly Casino Pass. |
| `/diamonds buy` | View current support and Diamond purchase information. |
| `/shop list type:Diamonds` | Browse items sold for Diamonds. |
| `/cosmetics shop [category]` | Browse permanent cosmetic unlocks. |

## Ways to spend Diamonds

### Diamond Market

The Diamond Market offers direct access to a dozen optional feature supplies. These purchases do not remove the existing credit, voting, drop, crate, or gameplay routes for obtaining the same items.

| Offer | Contents | Price |
| --- | ---: | ---: |
| Key Bundle | 5 Keys | 20 💎 |
| Standard Crate Bundle | 5 Standard Crates | 30 💎 |
| Customization Token | 1 token | 150 💎 |
| Plinko Ticket Pack | 5 tickets | 100 💎 |
| Voter Chip | 1 chip | 125 💎 |
| Magic 8 Ball | 1 ball | 60 💎 |
| Big Blind Chip | 1 chip | 35 💎 |
| Dealer Chip | 1 chip | 60 💎 |
| Deck of Cards | 1 deck | 90 💎 |
| Ace of Spades | 1 card | 120 💎 |
| Small Blind Chip | 1 chip | 80 💎 |
| Monopoly Table Pack | 5 Tables | 100 💎 |

Run `/diamonds market` for descriptions and redemption names. Use `/diamonds redeem <reward> [amount]` to purchase. Multiple bundles can be bought in one transaction, up to 25.

### Premium crates

Silver, Gold, Diamond, and Platinum Crates are purchased with Diamonds through `/shop buy`. Every crate also requires one universal Key when opened with `/crate open`.

| Crate | Diamond price |
| --- | ---: |
| Silver | 25 💎 |
| Gold | 75 💎 |
| Diamond | 175 💎 |
| Platinum | 400 💎 |

See [Crates](crates.md) for their reward ranges.

### Casino Pass XP

Use `/diamonds passxp <amount>` to buy between 50 and 1,000 XP at a time. Each XP costs **1 Diamond**. The command charges only for XP that fits below the monthly 3,000 XP maximum.

Example: `/diamonds passxp 100`

### Credit exchange

Use `/diamonds exchange <amount>` to convert between 10 and 1,000 Diamonds at a time. The fixed rate is:

> **1 Diamond = 100 Credits**

Example: `/diamonds exchange 100` awards 10,000 wallet Credits.

### Cosmetics and activities

* Unlock titles, crests, frames, auras, taglines, stat trackers, and illustrated backgrounds permanently in the [Cosmetic Locker](cosmetics.md).
* Buy Customization Tokens used for profile avatars, embed colors, and text colors.
* Buy Plinko Tickets required by `/plinko`.
* Browse all currently available Diamond items with `/shop list type:Diamonds`.

## Ways to earn Diamonds

* Vote using `/vote`.
* Claim daily tier rewards with `/donator`.
* Complete `/donorchallenges` when eligible.
* Claim Diamond rewards from Casino Pass.
* Open upgraded crate tiers that include guaranteed Diamond ranges.
* Use `/diamonds buy` for current support options.

## Donator value

Diamonds are included in every Donator tier's daily reward. Higher tiers receive more Diamonds, allowing members to choose how to use their perk instead of receiving only one fixed benefit.

| Tier | Base daily Diamonds |
| --- | ---: |
| Bronze | 10 |
| Silver | 15 |
| Gold | 25 |
| Diamond | 40 |
| Platinum | 75 |

Daily Donator streak bonuses can increase the final claim. See [Donator Membership](../donator.md) for the other tier benefits.
