# ℹ️ Profile

Your Casino profile brings together identity, progression, balance, statistics, and customization.

## Viewing profiles

* `/profile view [user]` — view your profile or another player's public profile.
* `/profile avatar` — view or manage profile avatar options.
* `/stats [user]` — detailed game totals.
* `/level` — level and XP progress.
* `/rank` — ranked-system status.

## Customization

Profile editing supports available background, embed-color, and text-color options. Use `/colors` to see recognized color choices, then use the matching `/profile edit` option.

The [Cosmetic Locker](../cosmetics.md) adds permanent Diamond-unlocked titles, crests, frames, auras, taglines, featured-stat trackers, and illustrated profile backgrounds. These unlock once and can then be swapped freely.

* `/cosmetics shop [category]` — browse cosmetics and prices.
* `/cosmetics buy <cosmetic>` — permanently unlock and equip a cosmetic.
* `/cosmetics locker` — view owned and equipped cosmetics.
* `/cosmetics equip <cosmetic>` — equip something already owned.
* `/cosmetics clear <slot>` — remove the current cosmetic from a slot.
* `/cosmetics shuffle` — randomize equipped slots from owned cosmetics.
