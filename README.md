# 👋 Welcome to The Casino

The Casino is a connected Discord economy and casino experience. Play interactive games, build your balance, collect and trade items, open crates, progress through Casino Pass, and manage the same account from the web dashboard.

## Start here

1. Invite The Casino to your Discord server.
2. Run `/start` in Discord to create your casino account.
3. Use `/help` to browse commands or `/balance` to confirm your account is ready.
4. Sign in to the dashboard with the same Discord account to see your live balance, inventory, auctions, history, achievements, and Casino Pass progress.

{% hint style="info" %}
Discord and the dashboard use the same economy. Credits, items, wagers, and rewards affect the same account.
{% endhint %}
